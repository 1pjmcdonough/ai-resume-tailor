# Configuration

This directory contains configuration files and templates for the Resume Tailor application.

## Contents

- Environment variable templates
- Configuration file examples
- Deployment configurations
- Development settings

## Environment Variables

Copy `.env.example` to `.env` and fill in your values:

```bash
cp .env.example .env
```

## Configuration Files

- `config.yaml` - Main application configuration
- `logging.yaml` - Logging configuration
- `streamlit_config.toml` - Streamlit specific settings

## Deployment

Different deployment configurations are available for various platforms:
- Docker
- Heroku
- AWS
- Local development
