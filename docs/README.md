# Documentation

This directory contains project documentation.

## Contents

- API documentation
- User guides
- Development documentation
- Architecture diagrams

## Building Documentation

Documentation can be built using various tools depending on your preference:

- **Sphinx**: `sphinx-build -b html docs/source docs/build/html`
- **MkDocs**: `mkdocs build`
- **GitBook**: `gitbook build`

## Contributing to Documentation

When adding new features or making changes, please update the relevant documentation files.
